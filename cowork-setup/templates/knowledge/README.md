# knowledge/ — o que o escritório SABE

Só entra aqui **modelo validado** (peça, contrato, cláusula, roteiro, checklist) que {{TRATAMENTO}} aprovou para reutilizar. Não é arquivo morto: contrato de terceiro, versão antiga e rascunho ficam no caso (`historico/`) ou em `_legado/`.

## Organização
- `knowledge/<area>/` — uma pasta por área (as mesmas de `contencioso/` e `consultivo/`): `civel/`, `trabalhista/`, `familia/`…
- `knowledge/templates/` — os modelos da mecânica: `STATE.template.md`, `STATE-cliente.template.md`, `FICHA.template.md`, `CADASTRO.template.md`. **Não editar sem atualizar a versão** (`_sistema/versao`).
- `knowledge/README.md` — este índice. Ao guardar modelo novo, acrescente uma linha na tabela abaixo.
