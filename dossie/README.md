# Dossiê do caso (v0.2)

Painel de consulta do Claude Code para bancadas jurídicas no método Code-OS / cowork-setup. Mostra, do caso
desta conversa (o projeto cujo STATE.md ou FICHA.md a conversa leu ou editou por último): decisões fixadas,
cronologia com o status de prova de cada fato, partes e foro, valor da causa ou do negócio, honorários (do
CADASTRO do cliente) e as peças produzidas na raiz do projeto. Só leitura, sem botões que executam.
Comando: `/dossie [clientes/<cliente>/<tipo>/<area>/<projeto>]`. Funciona sozinho ou ao lado da Bancada.
